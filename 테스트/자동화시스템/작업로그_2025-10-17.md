### 2. `edmt_automation.py` (11KB)
**용도**: Google Sheets 응답 데이터를 채점 엑셀로 자동 변환하는 Python 스크립트

**주요 기능**:
- Google Sheets API로 응답 데이터 읽기
- 200개 응답 자동 파싱
- 20개 방어기제별 원점수 계산
- 나이/성별에 따른 규준표 선택 (8개 규준표)
- 원점수 → 스텐점수 자동 변환
- 개인별 채점 엑셀 파일 자동 생성

**필수 라이브러리**:
```bash
pip install gspread oauth2client openpyxl
```

**실행 명령어**:
```bash
python3 edmt_automation.py \
  --sheet-url "https://docs.google.com/spreadsheets/.../응답시트URL" \
  --template "이화방어검사채점표 수정.xlsx" \
  --output-dir "./results"
```

**처리 흐름**:
```
Google Sheets 응답 읽기
    ↓
200개 문항 파싱 (① → 1, ② → 2, ...)
    ↓
방어기제별 원점수 계산 (각 10문항씩 합산)
    ↓
나이/성별로 규준표 선택
    ↓
스텐점수 변환
    ↓
개인별 엑셀 파일 생성
```

## 🐛 예상 문제 및 해결책

### 문제 1: "권한이 없습니다" 오류
**원인**: 서비스 계정이 시트에 접근 권한 없음
**해결**: 응답 시트를 서비스 계정 이메일과 공유 (편집자 권한)

### 문제 2: "credentials.json을 찾을 수 없습니다"
**원인**: 파일 경로 오류
**해결**: 파일을 Python 스크립트와 같은 폴더에 위치

### 문제 3: Forms가 생성되지 않음
**원인**: Apps Script 오류
**해결**:
- 로그 확인 (Ctrl+Enter)
- 권한 재승인
- 스크립트 재실행

### 문제 4: 응답이 제대로 파싱되지 않음
**원인**: Google Sheets 열 이름 불일치
**해결**:
- 첫 행이 헤더인지 확인
- 문항 번호 형식 확인 ("1. " 형식)

### 문제 5: 스텐점수가 이상함
**원인**: 규준표 참조 오류
**해결**:
- 나이/성별 코드 확인
- 규준표 시트 이름 확인
- 규준표 데이터 무결성 확인
