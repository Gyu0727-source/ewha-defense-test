## 시스템 개요

### 기존 방식 vs 자동화 방식

#### 기존 방식 ❌
```
PDF 검사지 → 내담자 펜으로 작성 → 수작업 입력 (200개!) → 결과 확인
                                    ↑
                              여기서 20분+ 소요
```

#### 자동화 방식 ✅
```
Google Form 링크 → 내담자 온라인 작성 → Python 스크립트 실행 (1초) → 결과 완성!
                                                ↑
                                          완전 자동!
```

### 장점
- ⏱️ **시간 절약**: 20분 → 1초
- ✅ **정확도 100%**: 입력 실수 제로
- 📱 **편의성**: 모바일/PC 모두 가능
- 📊 **데이터 관리**: 자동 저장 및 백업
- 🌐 **원격 검사**: 어디서든 가능

## 1단계: Google Forms 생성

### 1-1. Google Apps Script 준비

1. **Google Drive** (https://drive.google.com) 접속
2. **새로 만들기 → Google Sheets** 클릭
3. 시트 이름: "EDMT 관리"
4. **확장 프로그램 → Apps Script** 클릭

### 1-2. 스크립트 복사 & 실행

1. `/tmp/create_edmt_form_complete.gs` 파일 내용을 **모두 복사**
2. Apps Script 편집기에 **붙여넣기** (기존 코드 삭제 후)
3. **저장** (Ctrl+S 또는 💾 아이콘)
4. 함수 선택: **createEDMTForm** 선택
5. **실행** 버튼 (▶) 클릭
6. **권한 승인**:
   - "권한 검토" 클릭
   - 계정 선택
   - "고급" 클릭
   - "안전하지 않은 페이지로 이동" 클릭
   - "허용" 클릭

### 1-3. Form URL 확인

실행이 완료되면 팝업 창에 다음이 표시됩니다:

```
✅ 성공!
Form 링크:
https://forms.google.com/...

응답 시트:
https://docs.google.com/spreadsheets/...
```

**Form 링크**를 복사하여 저장하세요! (내담자에게 전송할 링크)

## 2단계: Google API 설정

Python 스크립트가 Google Sheets에 접근하려면 API 인증이 필요합니다.

### 2-1. Google Cloud Console 설정

1. **Google Cloud Console** (https://console.cloud.google.com) 접속
2. **새 프로젝트** 생성
   - 프로젝트 이름: "EDMT Automation"
3. **API 및 서비스 → 라이브러리** 이동
4. 다음 두 API 활성화:
   - **Google Sheets API**
   - **Google Drive API**

### 2-2. 서비스 계정 생성

1. **API 및 서비스 → 사용자 인증 정보**
2. **사용자 인증 정보 만들기 → 서비스 계정**
3. 서비스 계정 이름: "edmt-automation"
4. **완료** 클릭
5. 생성된 서비스 계정 클릭
6. **키** 탭 → **키 추가 → 새 키 만들기**
7. **JSON** 선택 → **만들기**
8. JSON 파일이 자동 다운로드됩니다

### 2-3. 인증 파일 설정

1. 다운로드한 JSON 파일 이름을 **`credentials.json`**으로 변경
2. Python 스크립트와 같은 폴더에 저장

### 2-4. Google Sheets 공유

1. 1단계에서 생성된 **응답 시트** 열기
2. **공유** 버튼 클릭
3. `credentials.json` 파일 안의 **`client_email`** 주소 복사
   - 예: `edmt-automation@...iam.gserviceaccount.com`
4. 이 이메일에게 **편집자** 권한 부여

## 3단계: Python 스크립트 실행

### 3-1. 필수 라이브러리 설치

```bash
pip install gspread oauth2client openpyxl
```

### 3-2. 스크립트 실행

```bash
python3 edmt_automation.py \
  --sheet-url "https://docs.google.com/spreadsheets/.../응답시트URL" \
  --template "이화방어검사채점표 수정.xlsx" \
  --output-dir "./results"
```

**파라미터 설명:**
- `--sheet-url`: 응답이 저장된 Google Sheets URL
- `--template`: 채점 템플릿 엑셀 파일 경로
- `--output-dir`: 결과 파일을 저장할 폴더 (선택사항, 기본값: ./results)

### 3-3. 실행 결과

스크립트가 다음을 수행합니다:

```
1. Google Sheets에서 모든 응답 읽기
2. 각 응답 파싱 (이름, 나이, 성별, 200개 응답)
3. 원점수 계산 (20개 방어기제별)
4. 규준표에 따른 스텐점수 변환
5. 채점 엑셀에 자동 입력
6. 개인별 결과 파일 생성
```

**출력 예시:**
```
✅ Google Sheets API 인증 성공
✅ 3개의 응답을 읽어왔습니다

============================================================
응답 1/3 처리 중...
============================================================
📝 이름: 홍길동, 나이: 35, 성별: 남
📊 원점수 계산 완료
✅ 엑셀 파일 저장 완료: ./results/홍길동_35세_남_결과.xlsx

============================================================
응답 2/3 처리 중...
============================================================
...
```

## 문제 해결

### Q1: "권한이 없습니다" 오류
**A:** Google Sheets를 서비스 계정 이메일과 공유했는지 확인하세요.

### Q2: "credentials.json을 찾을 수 없습니다"
**A:** JSON 파일이 Python 스크립트와 같은 폴더에 있는지 확인하세요.

### Q3: Forms가 제대로 생성되지 않음
**A:** Apps Script 실행 시 오류 로그를 확인하세요. 200개 문항이 모두 포함되었는지 확인하세요.

### Q4: 응답이 제대로 읽히지 않음
**A:** Google Sheets의 열 이름이 정확한지 확인하세요. 첫 행이 헤더여야 합니다.

### Q5: 엑셀 템플릿이 안 열림
**A:** 템플릿 파일 경로가 정확한지, 파일이 손상되지 않았는지 확인하세요.

## 추가 기능 (선택사항)

### 배치 처리 자동화

매일 특정 시간에 자동으로 처리하려면 **cron (Linux/Mac)** 또는 **Task Scheduler (Windows)**를 사용하세요.

**예시 (Linux/Mac):**
```bash
# crontab -e
0 18 * * * cd /path/to/script && python3 edmt_automation.py --sheet-url "..." --template "..."
```

이렇게 하면 매일 오후 6시에 자동으로 새 응답을 처리합니다!
